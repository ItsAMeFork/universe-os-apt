# Universe OS-updates (APT-pakketbron)

Ondertekende pakketbron voor [Universe OS](https://github.com/ItsAMeFork/universe-os). Universe OS-computers halen hier
updates van de interface en instellingen op, naast de normale Debian-bronnen.

- Kanalen: `stable` (voor iedereen) en `test` (alleen computers die testupdates aanzetten).
- Ondertekend met sleutel `771F 7DCD 1FB9 4C8D 5C4C  1B37 9D38 DB26 1B78 24AC` (`universe-os-updates.asc`).
- Wordt gemaakt met `scripts/publiceer-apt.sh` uit de hoofdrepository. Niet met de hand wijzigen.
